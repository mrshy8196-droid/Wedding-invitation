# 💍 دعوة زفاف أحمد ونور

موقع تفاعلي احترافي لتأكيد الحضور (RSVP) ودعوة حفل زفاف "أحمد ونور"، مصمم بعناية فائقة ليعطي طابعاً ملكياً وراقياً، مع ربط مباشر لتأكيد الحضور عبر تطبيق الواتساب.

## ✨ مميزات المشروع:
- **تصميم فخم ومتجاوب (Responsive Design):** يتناسب بسلاسة مع جميع أجهزة الهواتف الذكية والأجهزة اللوحية وأجهزة الكمبيوتر.
- **تأكيد الحضور (RSVP):** نظام مدمج يتيح للضيوف تسجيل أسمائهم، عدد الحضور، وكتابة رسائل التهنئة، وإرسالها فوراً بتنسيق احترافي ومنظم إلى رقم العريس عبر الواتساب.
- **خلفية صوتية هادئة:** دعم تشغيل الزفة الهادئة بدون موسيقى لخلق جو مبهج ومناسب لزفاف مبارك.
- **أكواد نظيفة وخالية من الأخطاء:** تم تطويره باستخدام أحدث تقنيات الـ HTML, CSS, و JavaScript.

## 🛠️ التقنيات المستخدمة:
- **HTML5** لتنظيم هيكل الموقع.
- **CSS3** للتصميم والألوان المتناسقة.
- **JavaScript** للتحكم في تفاعلية الفورم وتوليد رسالة الواتساب.
